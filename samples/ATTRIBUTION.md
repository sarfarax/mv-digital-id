# Sample portrait attribution

The photographs in this directory (`portrait-1.jpg` … `portrait-4.jpg`, and the
derived greyscale dumps and printed cards built from them) are AI-generated
faces produced by StyleGAN. They depict no real person. Each is marked public
domain on Wikimedia Commons:

| File | Source |
| --- | --- |
| `portrait-1.jpg` | [Light brown hair woman.jpg](https://commons.wikimedia.org/wiki/File:Light_brown_hair_woman.jpg) |
| `portrait-2.jpg` | [GAN deepfake white girl.jpg](https://commons.wikimedia.org/wiki/File:GAN_deepfake_white_girl.jpg) |
| `portrait-3.jpg` | [Woman 1.jpg](https://commons.wikimedia.org/wiki/File:Woman_1.jpg) |
| `portrait-4.jpg` | [This Person Does Not Exist example.jpg](https://commons.wikimedia.org/wiki/File:This_Person_Does_Not_Exist_example.jpg) |

Each is centre-cropped to 3:4. `portrait-a.rgba` is `portrait-2.jpg` and
`portrait-b.rgba` is `portrait-1.jpg`, resized to 300x400 and greyscaled.

They are bundled only so the demo issuer and scanner can be tried without a
camera or a separate photo file. The cards built from them are marked SPECIMEN
and are not identity documents.
