Pipeline tests

Runs the whole flow in this browser: hash a portrait, sign a card, draw a real QR code, synthesise a photograph of the finished card, then decode and verify it the way the scanner would. Includes a forged card, a card photographed at an angle, and an Enhanced card whose signed face code is checked against the holder and an impostor. The Enhanced group loads the face models, so the first run takes a few seconds longer.
